# 캐치캐치

캡처(ㅋㅊ)한 정보를 캐치해 두는 보관함. 트위터·인스타 등에서 찍은 캡처나 링크를 올리면 Gemini가 이미지 속 글자를 읽고, 요약·태그를 붙여 폴더에 정리해 줍니다. 구글로 로그인하면 내 구글 드라이브에 자동 백업됩니다.

## 1. GitHub Pages로 배포
1. 이 폴더의 파일을 모두 저장소 맨 위(루트)에 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main` / `(root)`로 저장합니다.
3. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 에서 열립니다.
4. 휴대폰 브라우저 메뉴에서 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.

## 2. AI 정리 켜기 (Gemini, 무료)
1. https://aistudio.google.com/app/apikey 에 구글 계정으로 들어가 **Create API key**를 누릅니다.
2. 앱 **설정 → AI 정리 · Gemini**에 키를 붙여넣고 **저장 → 연결 테스트**를 누릅니다.

무료 키로 보낸 내용은 구글이 서비스 개선에 쓸 수 있어요. 키가 없어도 직접 입력으로 저장·검색은 됩니다.

## 3. 구글 로그인 · 드라이브 백업 켜기 (처음 한 번)
구글 로그인에는 내 앱 전용 **OAuth 클라이언트 ID**가 필요합니다. Firebase 프로젝트가 있다면 그 프로젝트를 그대로 써도 됩니다.

1. https://console.cloud.google.com 에서 프로젝트를 고릅니다 (Firebase 프로젝트도 여기 보여요).
2. **API 및 서비스 → 라이브러리**에서 `Google Drive API`를 찾아 **사용**을 누릅니다.
3. **Google 인증 플랫폼(OAuth 동의 화면)**에서 시작하기를 눌러 앱 이름 `캐치캐치`, 대상 **외부**로 만듭니다.
   - **대상(Audience) → 테스트 사용자**에 내 Gmail 주소를 추가합니다.
4. **클라이언트 → 클라이언트 만들기**: 애플리케이션 유형 **웹 애플리케이션**
   - **승인된 JavaScript 원본**에 `https://<아이디>.github.io` 를 넣습니다 (뒤에 `/`나 저장소 이름 없이).
   - 만들기를 누르고 나오는 **클라이언트 ID**(`….apps.googleusercontent.com`)를 복사합니다.
5. 앱 **설정 → 구글 계정**에 클라이언트 ID를 붙여넣고 저장한 뒤 **구글 계정으로 로그인**을 누릅니다.
   - 권한 화면에서 드라이브 항목에 체크해 주세요.
   - (선택) `index.html` 맨 아래 스크립트의 `GOOGLE_CLIENT_ID = ''` 에 ID를 넣어두면 다른 기기에서 입력하지 않아도 됩니다.

### 백업 방식
- 내 드라이브에 **캐치캐치 백업** 폴더가 생기고, 캡처 목록(`catchcatch-data.json`)과 이미지 파일이 들어갑니다.
- 캡처를 저장·수정·삭제하면 몇 초 뒤 자동으로 드라이브와 맞춥니다. 로그인은 약 1시간 유지되고, 끊기면 홈에 백업 버튼이 뜹니다.
- 새 기기에서 로그인하면 드라이브의 캡처를 불러와 합칩니다.
- 앱은 자기가 만든 파일에만 접근할 수 있어요 (drive.file 권한).

## 데이터
캡처와 이미지는 기기의 브라우저(IndexedDB)에 저장되고, 구글 로그인 시 드라이브에도 백업됩니다. 설정의 **파일로 백업**으로 직접 백업 파일을 받을 수도 있어요.

## 파일
- `index.html` 앱 전체
- `logo.svg`, `logo-white.svg` 로고 (밝은 배경용 / 어두운 배경용)
- `favicon.svg`, `favicon-32.png` 브라우저 탭 아이콘
- `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `apple-touch-icon.png` 홈 화면 아이콘
- `manifest.webmanifest` 홈 화면 앱 설정
